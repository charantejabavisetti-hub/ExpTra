# Expense Tracker (React JS Version)

Converted from the static HTML/CSS/JS `ExpTra` project into a React + Vite Single-Page Application using `react-router-dom` and React Context (`localStorage` persistence).

## Run Locally
```bash
npm install
npm run dev
```
